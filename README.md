# 경영기획팀 업무포탈

산발적으로 흩어진 팀 업무 시스템을 **한 곳에서 접속·관리**하는 포탈 사이트입니다.
별도 설치·빌드 없이 `index.html` 하나로 동작합니다.

🔗 **배포 주소**: https://sitacule.github.io/potal/

---

## 주요 기능

- **모던 그룹웨어 대시보드** — 다크 사이드바 + 통계 카드 + 업무시스템 타일 + 위젯(오늘 일정·공지·최근 이용)
- **개인 로그인** — 담당자별 회사 이메일로 가입/로그인, 사용자마다 개인 대시보드 구성 저장
- **관리자 승인제** — 신규 가입은 `승인 대기` → 관리자 승인 후 이용
- **가입 자동 알림** — 관리자에게 🔔 알림(카운트·로그인 시 토스트·패널 즉시 승인)
- **업무 시스템 타일** — 클릭 시 각 시스템으로 이동, 편집 모드에서 추가/수정/삭제/순서변경
- **계정 연동(SSO 골격)** — 시스템별 로그인 아이디 저장(향후 SSO 자동 로그인 확장 대비)

## 관리자 지정

관리자 이메일은 소스에 **평문으로 저장하지 않고 SHA-256 해시값**만 넣습니다
(`ADMIN_EMAIL_HASHES`). 해당 이메일로 가입하면 자동 승인 + 관리자 권한이 부여됩니다.

> ⚠️ **관리자가 가장 먼저 가입해야 합니다.** 관리자가 가입하기 전에 다른 직원이 먼저
> 가입하면, 승인해 줄 사람이 없어 계속 대기 상태가 됩니다.

해시 생성:
```bash
printf '%s' "이메일(소문자)" | sha256sum
```

## 참고 (현재 단계의 한계)

- 계정·승인·구성은 **브라우저 localStorage**에 저장됩니다. 따라서 승인·알림은 같은
  브라우저 안에서 완결되며, 여러 PC 간 실시간 연동·자동 로그인은 회사 SSO 또는 포탈
  백엔드 도입 시 완성됩니다.
